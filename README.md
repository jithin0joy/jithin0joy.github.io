### 1. Comprehensive Study on Mobile Ad-hoc Routing Protocols: OLSR, AODV and DSDV

**IEEE GCAT 2022 | Published Conference Research | MCA Semester 4**

📄 **[View Published Paper on IEEE Xplore](https://ieeexplore.ieee.org/document/9971899/)**

📁 **[View Research Project](Projects/manet-routing-protocols/)**

**Authors:** Jisha R C, Jithin Joseph and Muhammed Nadeem Mohammed Basheer

**Conference:** 3rd Global Conference for Advancement in Technology (GCAT), 2022

**Research Area:** Wireless Networks, Network Simulation, Routing Protocols and Performance Analysis

#### Research Overview

This research investigated the performance of routing protocols in **Mobile Ad-hoc Networks (MANETs)**, where wireless devices communicate without relying on fixed network infrastructure.

The study compared three routing protocols:

- **AODV:** Ad-hoc On-Demand Distance Vector
- **OLSR:** Optimized Link State Routing
- **DSDV:** Destination-Sequenced Distance Vector

Using Network Simulator 3 (NS-3), we evaluated protocol performance under varying network sizes and mobility conditions.

#### Research Methodology

The simulations considered networks containing 20, 30 and 50 mobile nodes.

Performance was evaluated using:

- Packet Delivery Ratio (PDR)
- Packet Loss Ratio (PLR)
- Average Throughput
- End-to-End Delay

#### Key Findings

The study identified important performance trade-offs between reactive and proactive routing protocols.

AODV generally demonstrated higher throughput under the evaluated conditions, although it also experienced higher end-to-end delay.

The results highlighted how network topology, mobility and routing strategy influence communication performance.

### 2. A Study on Graph Partitioning & Graph Neural Network Systems

**MCA Semester 3 | Academic Dissertation Research**

📁 **[View Research Project](Projects/graph-partitioning-gnn/)**

**Researchers:** Jithin Joseph and Muhammed Nadeem Mohammed Basheer

**Academic Guide:** Jisha R C

**Institution:** Amrita Vishwa Vidyapeetham

**Research Area:** Graph Theory, Graph Machine Learning, Network Partitioning and Recommendation Systems

#### Research Overview

This collaborative research investigated graph partitioning algorithms and Graph Neural Network (GNN) architectures.

The study explored how complex networks can be represented, partitioned and analysed using graph-based computational techniques.

The research covered:

- Kernighan–Lin graph partitioning
- Spectral graph partitioning
- Multilevel graph partitioning
- Graph Convolutional Networks (GCN)
- GraphSAGE
- Graph Attention Networks (GAT)
- Gated Graph Neural Networks (GGNN)

#### Proposed Application

The research proposed a graph-based freelancer–job recommendation system.

The conceptual architecture investigated representing freelancers, jobs and their interactions as a graph to support recommendation generation.

The original dissertation included a spectral partitioning demonstration using sample graph data.

The proposed GNN recommendation model remained conceptual and was not fully implemented or evaluated.

#### Current GitHub Implementation

The repository includes a **new reproducible educational reconstruction** of graph partitioning experiments using Python, NetworkX, NumPy and SciPy.

This implementation compares Kernighan–Lin and spectral partitioning on synthetic graph data.

The reconstructed experiments are separate from the original university dissertation and are not presented as its historical experimental results.

#### Knowledge and Skills Developed

- Graph theory and network representations
- Graph Laplacian matrices and eigenvectors
- Spectral clustering and partitioning
- Graph Neural Network architectures
- Recommendation-system concepts
- Machine learning literature review
- Algorithm evaluation and research limitations
