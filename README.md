## Featured academic project

### [Graph Partitioning & GNN Systems — MCA Semester 3 Research](Projects/graph-partitioning-gnn/)

My collaborative MCA research at Amrita Vishwa Vidyapeetham explored Kernighan–Lin and spectral graph partitioning, surveyed graph neural networks (GCN, GraphSAGE, GAT, GGNN), and proposed a graph-based freelancer–job recommendation system. The original work demonstrated spectral partitioning on sample graph data; the GNN recommender remained a conceptual design. This repository includes a **new reproducible educational reconstruction** of partitioning experiments, explicitly distinguished from the original dissertation.

**Research collaborators:** Jithin Joseph and Muhammed Nadeem Mohammed Basheer. **Academic guide:** Jisha R C.
